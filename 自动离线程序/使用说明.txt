月度按需 Excel 自动化工具使用说明

一、用途
本文件夹用于放置离线按需启动的月度 Excel 自动化程序。
月底需要处理定编 Excel 时，双击“启动月度处理.bat”，选择本次 Excel 文件，程序会自动调用项目里的处理逻辑并输出结果。

二、使用步骤
1. 确认电脑已安装 Python，并已在项目根目录安装依赖：
   python -m pip install -r requirements.txt

2. 双击本文件夹中的：
   启动月度处理.bat

3. 在弹出的窗口中选择本次要处理的 Excel 文件。
   程序启动时会自动创建项目根目录下的 inputs 文件夹，并默认打开该文件夹。
   你也可以在文件选择窗口中切换到其他目录选择 Excel。
   当前默认流程需要选择已经完成滚筒/波轮大类区分、并且主表中包含“类型”列的当前结果文件。

4. 等待程序处理完成。
   完成后会弹窗显示最终输出文件路径，并自动打开项目根目录下的 outputs 文件夹。

三、当前默认流程
当前月度流程配置在 monthly_flow.json 中：
   stages = ["decompose-extra-summary", "classify"]

这表示工具会先生成“额外订单信息汇总”和“各线体分类明细表”，再执行现有分类结果输出。
由于 decompose-extra-summary 依赖主表中的“类型”列，请不要直接选择完全原始、尚未完成排单分解的 Excel。
后续如果继续新增自动化阶段，可以继续扩展 monthly_flow.json 中的 stages。

四、输出和日志
1. 输出结果默认保存在项目根目录下的 outputs 文件夹。

2. 每次运行都会在本文件夹下的 logs 文件夹中生成运行日志。
   日志会记录选择的 Excel、执行的阶段、每一步输出文件、失败原因和详细错误。

3. 如果处理失败，程序会弹窗显示简短错误原因。
   详细信息请查看 logs 文件夹中最新的 monthly_run_*.log。

五、注意事项
1. 请不要选择文件名以 ~$ 开头的 Excel 临时文件。
   这种文件通常表示原 Excel 正在被打开或锁定。

2. 原始 Excel 不会被直接修改。
   程序会把处理结果写到 outputs 文件夹。

3. 本工具不使用 Windows 任务计划程序，也不会后台常驻运行。
   只有你双击启动时才会执行。

六、文件说明
monthly_runner.py      月度离线启动主程序
monthly_flow.json      月度流程配置文件
启动月度处理.bat       双击启动脚本
使用说明.txt           本说明文档
logs                  每次运行的日志文件夹
